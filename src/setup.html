Setup guide

The extension is the interface. A tiny local helper does the actual downloading with yt-dlp, so every resolution and audio track works reliably.

1 Install the three tools

Open PowerShell and run:

winget install OpenJS.NodeJS.LTS
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg

Close and reopen PowerShell afterwards, then confirm all three respond:

node --version
yt-dlp --version
ffmpeg -version

Already have them? Skip to step 2. ffmpeg is only needed for merging HD video with audio.

2 Start the companion

In the extension folder, double-click:

server\start.bat

Keep that window open while you download. It listens only on 127.0.0.1:8765 and is not reachable from the internet. Press Ctrl + C to stop it.

3 Load the extension

  • Open chrome://extensions.
  • Turn on Developer mode (top right).
  • Click Load unpacked and pick the youtube-downloader folder.
  • Pin the extension, then reload any open YouTube tab.

4 Use it

Open any YouTube video. A download icon appears in the player controls next to the settings button. Click it to see every available resolution, file size, codec and audio bitrate, then pick one.

The panel has Video and Audio tabs. HD video is merged with the best audio track automatically and saved to your normal Downloads folder.

Troubleshooting

  • “Companion app is offline” — the start.bat window is closed or the port is different. Start it, then use the retry button in the panel.
  • yt-dlp errors on a video — update it with yt-dlp -U. YouTube changes often.
  • No 1080p or higher — that video may only offer lower resolutions, or you may be seeing a members-only / age-restricted stream.
  • Downloads are slow — YouTube throttles some streams. The helper fetches with multiple connections, but large 4K files still take a while.

Download only videos you own or have permission to use, and respect YouTube’s Terms of Service and local copyright law.
